# Interface fonts

The desktop app's interface uses the same fonts as the web UI, built into the app so it works
offline: [Inter](https://rsms.me/inter/) (Medium, SemiBold; Regular and Bold come from
`Tapeory.Api/Fonts/Inter`) and [Space Grotesk](https://github.com/floriankarsten/space-grotesk)
(Medium, SemiBold, Bold). Both are licensed under the SIL Open Font License 1.1: see
`OFL-SpaceGrotesk.txt` here and `Tapeory.Api/Fonts/licenses/OFL-1.1.txt` for Inter.
